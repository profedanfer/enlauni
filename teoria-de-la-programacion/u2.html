01Repaso

Criterios de diseño

Hoare resume los criterios objetivos de un buen lenguaje en cinco: simplicidad, seguridad, traducción rápida, código objeto eficiente y legibilidad (Hoare, 1973).

Legibilidad

Para Hoare, la legibilidad de los programas es inmensamente más importante que la facilidad para escribirlos (Hoare, 1973). El Zen de Python lo expresa en una línea: Readability counts (la legibilidad cuenta) (Peters, 2004).

Seguridad y confiabilidad

Hoare llama seguridad a que los errores de un programa nunca produzcan efectos que dependan de la máquina o de la implementación (Hoare, 1973).

Java se diseñó para software robusto, altamente confiable y seguro; exige declaraciones explícitas y no admite las declaraciones implícitas al estilo de C (Gosling y McGilton, 1996). Su tipado estático y fuerte ayuda a detectar errores al compilar (Oracle, s.f.-a), y corregir un error de compilación es más fácil que corregir uno de ejecución (Oracle, s.f.-b).

Eficiencia

Hoare incluye dos criterios de eficiencia: traducción rápida y código objeto eficiente (Hoare, 1973). La compilación a código máquina ofrece mayor eficiencia; la interpretación, mayor flexibilidad (Gallardo et al., 2025, §5.1–5.2).

Para medir duraciones cortas en Python se usa time.perf_counter(); su punto de referencia no está definido, así que solo vale la diferencia entre dos llamadas (Python Software Foundation, s.f.-c).

Regularidad

Un lenguaje regular evita los casos especiales. El Zen de Python lo dice así: Special cases aren't special enough to break the rules (los casos especiales no son tan especiales como para romper las reglas) (Peters, 2004).

  • Regla general: en Python, for recorre cualquier secuencia u objeto iterable (Python Software Foundation, s.f.-b).
  • Caso especial: en C, la expresión de un switch debe ser de tipo entero (char, entero o enumeración) (cppreference.com, s.f.); por eso no se puede usar con cadenas.
Portabilidad

Java genera bytecode neutral respecto de la arquitectura y especifica el tamaño de todos sus tipos primitivos, para que un programa se comporte igual en cualquier plataforma (Gosling y McGilton, 1996). La documentación de Python indica que el lenguaje es portable y corre en muchas variantes de Unix, en Mac y en Windows (Python Software Foundation, s.f.-a).

No confundas

Fácil de escribir no es lo mismo que fácil de leer. Hoare da prioridad a la legibilidad sobre la facilidad de escritura (Hoare, 1973). Cuando compares lenguajes, di siempre qué criterio estás evaluando.

Para comparar tiempos, mide. Usa el mismo tamaño de entrada, repite varias corridas y calcula la diferencia entre dos llamadas a perf_counter() (Python Software Foundation, s.f.-c).

02Código comparado

Recorrer una secuencia

Tres formas de recorrer la misma secuencia. Fíjate cuánto tiene que escribir el programador en cada caso y qué controla.

numeros = [1, 2, 3]
for numero in numeros:      # el mismo for sirve para tuplas y conjuntos
    print(numero)

Salida al ejecutarlo: 1, 2 y 3 en líneas separadas

int[] numeros = {1, 2, 3};
for (int numero : numeros) {     // for mejorado
    System.out.println(numero);
}

Salida al ejecutarlo: 1, 2 y 3 en líneas separadas

int numeros[3] = {1, 2, 3};
for (int i = 0; i < 3; i++) {    /* control manual del índice */
    printf("%d\n", numeros[i]);
}

Salida al ejecutarlo: 1, 2 y 3 en líneas separadas

03Actividades de práctica

Cada actividad indica cuándo terminaste. No pases a la siguiente hasta cumplirlo.

Actividad 1 · Rúbrica comparativa

En equipo de trabajo · 45 min

Tarea: leer 10 números y mostrar el mayor.

  1. Escriban la tarea en Python y en Java (C es opcional).
  2. Cuenten en cada versión: líneas, palabras reservadas y declaraciones de tipo.
  3. Puntúen de 1 a 5 cada lenguaje en los cinco criterios de Hoare.
  4. Justifiquen cada puntaje con algo visible en su propio código.

Terminaste cuando la tabla tiene 10 puntajes (15 si incluyen C) y cada uno cita una línea concreta de su código.

Actividad 2 · Cazadores de casos especiales

Individual · 30 min

Pistas para buscar: qué tipos acepta switch en C; la diferencia entre int e Integer en Java (busca «autoboxing»); qué produce (5) y qué produce (5,) en Python (busca «lista de expresiones» en la referencia del lenguaje).

  1. Encuentra 2 casos especiales: uno en C o Java y otro en Python.
  2. Escribe y ejecuta el código que muestra cada uno.
  3. Cita la documentación oficial que describe cada caso.
  4. Explica en una oración qué regla general rompe cada caso.

Terminaste cuando tienes 2 casos con código ejecutado, una cita oficial para cada uno y la regla que rompen.

Actividad 3 · Medir antes de opinar

Individual · 25 min
  1. En Colab construye una lista de 1 000 000 de números de dos formas: con append dentro de un bucle y con una comprensión de listas.
  2. Mide cada versión 5 veces con time.perf_counter().
  3. Calcula el promedio de cada versión.
  4. Escribe qué versión fue más rápida en tu computadora y por qué crees que pasa.

Terminaste cuando tienes una tabla con 5 mediciones por versión, los dos promedios y una explicación.
