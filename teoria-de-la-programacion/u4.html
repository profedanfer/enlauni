01Repaso

Tipo de dato

Los tipos limitan los valores que puede tener una variable o producir una expresión, limitan las operaciones permitidas y determinan su significado (Oracle, s.f.-f).

Estático o dinámico

Responde cuándo se verifican los tipos. Un lenguaje es de tipado estático si hace la verificación en tiempo de compilación, y de tipado dinámico si la hace en tiempo de ejecución (Oracle, s.f.-c).

  • Java es estático: cada variable y expresión tiene un tipo conocido al compilar (Oracle, s.f.-f).
  • Python es dinámico: los objetos tienen tipo, pero se determina en ejecución (Why is Python a dynamic language…, 2026).
Fuerte o débil

Responde si el lenguaje convierte los tipos por su cuenta. Un lenguaje de tipado fuerte impide ejecutar una operación cuando sus argumentos tienen un tipo incorrecto; uno débil convierte implícitamente esos argumentos (Oracle, s.f.-c).

  • Java es fuerte (Oracle, s.f.-f).
  • Python es fuerte: no se pueden sumar números y cadenas (Why is Python a dynamic language…, 2026).
  • En JavaScript, 'x' + 3 da 'x3'; es el ejemplo de tipado débil que usa la wiki de Python (Why is Python a dynamic language…, 2026).

Los dos ejes son independientes: tanto los lenguajes estáticos como los dinámicos pueden tener tipado fuerte o débil (Oracle, s.f.-c).

Tipos simples

Java tiene ocho tipos primitivos: byte, short, int, long, float, double, boolean y char. String no es técnicamente un tipo primitivo (Oracle, s.f.-e). El compilador convierte automáticamente entre un primitivo y su clase envoltorio, por ejemplo de int a Integer (autoboxing) (Oracle, s.f.-a).

División: en Python, / siempre devuelve un número de punto flotante y // hace la división entera (Python Software Foundation, s.f.-c). En C, la división entre enteros se trunca hacia cero (cppreference.com, s.f.-a). En Java, la división entera por cero lanza ArithmeticException (Oracle, s.f.-g).

Constructores de tipos

Permiten crear tipos nuevos a partir de otros.

  • En Python, las listas son mutables y las tuplas inmutables (Python Software Foundation, s.f.-b).
  • Un conjunto es una colección no ordenada y sin elementos repetidos (Python Software Foundation, s.f.-b); en Java, las implementaciones de Set no permiten duplicados (Oracle, s.f.-d).
  • Un diccionario guarda pares clave:valor con claves únicas, que deben ser de tipo inmutable (Python Software Foundation, s.f.-b); en Java, un Map no puede contener claves duplicadas (Oracle, s.f.-b).
  • En C, un struct es una secuencia de miembros almacenados en orden (cppreference.com, s.f.-b).
  • Los record de Java son clases que transportan datos inmutables de forma transparente (Bierman, 2020).
  • En Python, @dataclass genera métodos como __init__ y __repr__, pero no examina el tipo escrito en las anotaciones (Python Software Foundation, s.f.-a).
Del registro a la clase

El registro Estudiante (documento, nombre, teléfono, promedio) agrupa datos. En la Unidad 7 lo convertimos en una clase, que además tiene comportamiento y protege su estado.

No confundas

Dinámico no significa débil. Son ejes independientes (Oracle, s.f.-c). Python es dinámico y fuerte (Why is Python a dynamic language…, 2026).

No confundas tipado con ligadura. Tipado estático o dinámico (U4) es cuándo se verifican los tipos; ligadura estática o dinámica (U3) es cuándo se asocia un atributo a una variable.

02Código comparado

El registro Estudiante

El mismo registro en tres lenguajes. En Python, las anotaciones de tipo documentan los campos, pero @dataclass no las verifica.

from dataclasses import dataclass

@dataclass
class Estudiante:
    documento: str
    nombre: str
    telefono: str
    promedio: float

e = Estudiante("4567890", "Ana Benítez", "0981 123 456", 4.2)
print(e.nombre, e.promedio)

Salida al ejecutarlo: Ana Benítez 4.2

record Estudiante(String documento, String nombre,
                  String telefono, double promedio) {}

public class Main {
    public static void main(String[] args) {
        Estudiante e = new Estudiante("4567890", "Ana Benítez",
                                      "0981 123 456", 4.2);
        System.out.println(e.nombre() + " " + e.promedio());
    }
}

Salida al ejecutarlo: Ana Benítez 4.2

#include <stdio.h>

struct Estudiante {
    char documento[12];
    char nombre[40];
    char telefono[16];
    float promedio;
};

int main(void) {
    struct Estudiante e = {"4567890", "Ana Benítez", "0981 123 456", 4.2f};
    printf("%s %.1f\n", e.nombre, e.promedio);
    return 0;
}

Salida al ejecutarlo: Ana Benítez 4.2

03Actividades de práctica

Cada actividad indica cuándo terminaste. No pases a la siguiente hasta cumplirlo.

Actividad 1 · Laboratorio de tipos

En equipo de trabajo · 40 min
  1. Ejecuten en Python, Java y C tres operaciones: sumar un texto y un número; dividir 7 entre 2; asignar un decimal a una variable entera.
  2. Registren el resultado o el error, y si apareció al compilar o al ejecutar.
  3. Clasifiquen cada lenguaje como estático o dinámico, y como fuerte o débil, usando las definiciones citadas en esta unidad.
  4. Justifiquen cada clasificación con una celda de su tabla.

Terminaste cuando tienen una tabla de 9 celdas (3 operaciones × 3 lenguajes) con resultado y momento, y cada clasificación está justificada.

Actividad 2 · Elige el constructor

Individual · 30 min

Situaciones: (a) los asistentes a una charla, sin repetir; (b) buscar un producto por su código de barras; (c) la latitud y longitud de una sede, que no deben cambiar; (d) las notas de un examen en orden de entrega; (e) los datos de un estudiante.

  1. Elige un constructor de Python y su equivalente en Java para cada situación.
  2. Justifica cada elección con una propiedad: orden, duplicados, mutabilidad o acceso por clave.
  3. Escribe una línea de código que cree cada uno y ejecútala.

Terminaste cuando las 5 situaciones tienen constructor en los dos lenguajes, una propiedad que lo justifica y código que se ejecuta sin error.

Actividad 3 · Del registro a la colección

Individual · 30 min
  1. Crea el registro Estudiante en Python (@dataclass) o en Java (record).
  2. Arma una lista con 4 estudiantes.
  3. Arma un diccionario o HashMap que permita buscarlos por documento.
  4. Muestra el nombre del estudiante con documento "4567890" usando el mapa.

Terminaste cuando tu programa encuentra al estudiante por documento sin recorrer la lista.
