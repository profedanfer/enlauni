01Repaso

Expresión y enunciado

Una expresión es una construcción que puede evaluarse hasta dar un valor. Una sentencia (enunciado) es parte de un bloque de código: puede ser una expresión o una construcción con palabra clave, como if, while o for. En Python, las asignaciones son sentencias, no expresiones (Python Software Foundation, s.f.-c).

Precedencia

Indica qué operador se resuelve primero. La referencia de Python tiene una tabla de precedencia desde la más alta hasta la más baja (Python Software Foundation, s.f.-b). En Java, los operadores con mayor precedencia se evalúan antes que los de menor precedencia (Oracle, s.f.-b).

Asociatividad

Con operadores de igual precedencia, Python agrupa de izquierda a derecha, excepto la potencia y las expresiones condicionales, que agrupan de derecha a izquierda (Python Software Foundation, s.f.-b). Por eso 10 - 3 - 2 da 5 y 2 ** 3 ** 2 da 512. La potencia se vincula más fuerte que un operador unario a su izquierda (Python Software Foundation, s.f.-b): -2 ** 2 da -4.

En Java, todos los operadores binarios se evalúan de izquierda a derecha, salvo los de asignación (Oracle, s.f.-b).

Cortocircuito

En Python, x and y evalúa primero x; si es falso, devuelve su valor sin evaluar y. x or y no evalúa y si x es verdadero (Python Software Foundation, s.f.-b). Java (Oracle, s.f.-a) y C (cppreference.com, s.f.-c) tienen el mismo comportamiento con && y ||.

Esto permite poner una guarda dentro de la misma condición: x != 0 and 10 / x > 1.

Enunciados condicionales

Simples (if), dobles (if/else), anidados y múltiples (elif, switch). Python tiene además la sentencia match para coincidencia de patrones (Python Software Foundation, s.f.-d). En C, el switch solo admite expresiones de tipo entero (cppreference.com, s.f.-d).

Guarda

Dijkstra definió el comando con guarda como una lista de sentencias precedida por una expresión booleana; esa lista solo se ejecuta en un estado en que la guarda es verdadera (Dijkstra, 1974).

En la práctica, una guarda es una condición que se verifica antes de ejecutar una operación que podría fallar, por ejemplo dividir solo si el divisor no es cero.

Excepción

Evento que ocurre durante la ejecución y que interrumpe el flujo normal de las instrucciones. El sistema busca un manejador en la pila de llamadas, desde el método donde ocurrió el error hacia atrás; si no lo encuentra, el programa termina (Oracle, s.f.-d).

En Python, los errores detectados durante la ejecución se llaman excepciones y se manejan con try/except. raise fuerza una excepción y la cláusula finally siempre se ejecuta (Python Software Foundation, s.f.-a). En Java, el bloque finally también se ejecuta siempre que termina el bloque try (Oracle, s.f.-c).

Errores en C

try, catch y throw no figuran entre las palabras reservadas de C (cppreference.com, s.f.-a). Varias funciones de la biblioteca estándar indican errores escribiendo un entero positivo en errno (cppreference.com, s.f.-b).

No confundas

Una guarda actúa antes; una excepción, después. La guarda solo deja ejecutar el código si su condición es verdadera (Dijkstra, 1974). La excepción aparece cuando el error ya ocurrió durante la ejecución (Oracle, s.f.-d).

02Código comparado

Guarda para el divisor, excepción para el formato

La guarda previene la división por cero. La excepción reacciona cuando el texto que escribe la persona no es un número.

def dividir(a, b):
    if b == 0:                      # guarda
        return None
    return a / b

try:
    n = int(input("Divisor: "))     # el texto puede no ser un número
    print(dividir(10, n))
except ValueError:
    print("Eso no es un número entero")

Salida al ejecutarlo: Con 4: 2.5 · con 0: None · con «4a»: Eso no es un número entero

import java.util.Scanner;

public class Division {
    static Double dividir(double a, double b) {
        if (b == 0) return null;          // guarda
        return a / b;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        try {
            int n = Integer.parseInt(sc.nextLine());
            System.out.println(dividir(10, n));
        } catch (NumberFormatException e) {
            System.out.println("Eso no es un número entero");
        }
    }
}

Salida al ejecutarlo: Con 4: 2.5 · con 0: null · con «4a»: Eso no es un número entero

#include <stdio.h>
#include <stdlib.h>

int dividir(double a, double b, double *res) {
    if (b == 0) return -1;          /* guarda: código de error */
    *res = a / b;
    return 0;
}

int main(void) {
    char texto[32], *fin;
    double r;
    fgets(texto, sizeof texto, stdin);
    long n = strtol(texto, &fin, 10);
    if (fin == texto) {             /* no se leyó ningún número */
        printf("Eso no es un número entero\n");
        return 1;
    }
    if (dividir(10, n, &r) != 0) printf("No se puede dividir por cero\n");
    else printf("%.2f\n", r);
    return 0;
}

Salida al ejecutarlo: Con 4: 2.50 · con 0: No se puede dividir por cero · con «a»: Eso no es un número entero

Cada actividad indica cuándo terminaste. No pases a la siguiente hasta cumplirlo.

Actividad 1 · ¿Guarda o excepción?

Individual · 30 min

Situaciones: (1) promedio de una lista que puede estar vacía; (2) leer un número que escribe el usuario; (3) abrir un archivo cuyo nombre escribe el usuario; (4) validar que una edad esté entre 0 y 120; (5) obtener el quinto elemento de una lista de largo desconocido; (6) consultar el clima en un servicio de internet; (7) aplicar un descuento solo si el monto es positivo; (8) convertir a fecha un texto como «31/02/2026».

  1. Decide guarda o excepción para cada situación.
  2. Escribe una línea de justificación respondiendo: ¿puedo prever el error con una condición simple?
  3. Implementa en Python dos situaciones: una con guarda y otra con excepción.

Terminaste cuando las 8 situaciones tienen decisión y justificación, y tus dos programas no se detienen con ninguna entrada que pruebes.

Actividad 2 · Traza la precedencia

Individual · 20 min

Expresiones:

2 + 3 * 4 ** 2
(2 + 3) * 4 ** 2
-2 ** 2
10 - 4 - 3
not 3 > 5 and 2 == 2
True or False and False
  1. Resuelve cada expresión a mano, paso por paso, escribiendo el orden en que aplicas los operadores.
  2. Verifica cada resultado en Colab.
  3. Para cada diferencia entre tu resultado y Colab, busca en la tabla de precedencia de la referencia de Python qué regla aplicaste mal.

Terminaste cuando las 6 expresiones tienen su traza a mano y coinciden con Colab, o explicaste cada diferencia con la tabla.

Actividad 3 · Mismo control, tres lenguajes

En equipo de trabajo · 45 min

Programa: pide el precio de un producto en guaraníes y la cantidad, y muestra el total.

  1. Definan al menos 3 entradas inválidas que podrían ocurrir.
  2. Implementen en Python y Java: guardas para las reglas de negocio y excepciones para el formato.
  3. Implementen en C con guardas y códigos de retorno.
  4. Prueben las tres versiones con las 3 entradas inválidas.

Terminaste cuando las tres versiones responden con un mensaje claro a las 3 entradas inválidas sin terminar con error.
