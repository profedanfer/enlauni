¿Cómo se corrige una justificación? Un ejemplo

Ítem: print(True + 2) en Python. Opción elegida: 3 (correcta). Lo que cambia el puntaje es «Lo decide»:

2 ptsCompleta: «Conversión implícita: en Python bool es un subtipo de int y True vale 1, por eso True + 2 da 3 sin error, mientras que "3" + 2 sí da TypeError». Nombra el concepto, señala el código y explica el mecanismo.
1 ptIncompleta: «Porque True es 1». Es cierto, pero no nombra el concepto ni explica por qué Python lo permite.
0 ptsRazonamiento equivocado: «Porque Python tiene tipado débil y convierte cualquier cosa a número». Acierta la opción con una idea falsa: Python es fuerte.
0 ptsSin justificación, aunque la opción sea correcta.
