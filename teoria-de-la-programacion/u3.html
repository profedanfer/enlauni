01Repaso

Ligadura

En Python, los nombres refieren a objetos y se introducen mediante operaciones de vinculación (ligadura) (Python Software Foundation, s.f.-c, §4.2.1). Una variable puede tener ligados distintos atributos, y cada uno se liga en un momento distinto:

  • Tipo. En Java, cada variable y cada expresión tienen un tipo conocido en tiempo de compilación: la ligadura de tipo es estática (Oracle, s.f.-c). En Python, el tipo pertenece al objeto y se determina en tiempo de ejecución (Why is Python a dynamic language…, 2026): es dinámica.
  • Valor. En Java, si una constante static final es de tipo primitivo o String y su valor se conoce al compilar, el compilador la reemplaza por ese valor en todo el código (Oracle, s.f.-d). Una variable común recibe su valor durante la ejecución.
  • Almacenamiento. En C, una variable automática recibe su espacio al entrar al bloque y lo pierde al salir; una variable estática lo tiene durante toda la ejecución (cppreference.com, s.f.-b).
Tabla de símbolos

Tabla de búsqueda cuyas claves son identificadores y cuyos valores indican a qué se refiere cada uno (Nystrom, 2021a). En Python, cada ejecución de una función crea una tabla de símbolos local. Para resolver un nombre se busca primero en la local, luego en la de las funciones envolventes, después en la global y al final en la de nombres predefinidos (Python Software Foundation, s.f.-d).

Alcance

El alcance (scope) define la visibilidad de un nombre en un bloque (Python Software Foundation, s.f.-c, §4.2.2).

  • Léxico (estático): la asociación se determina en tiempo de compilación (Gallardo et al., 2025b, §4). Basta leer el texto del programa para saber a qué declaración se refiere un nombre; la mayoría de los lenguajes modernos funciona así (Nystrom, 2021b).
  • Dinámico: la asociación se determina en tiempo de ejecución (Gallardo et al., 2025b, §4).

Al conjunto de variables disponibles en una parte del programa se lo llama contexto o entorno (Gallardo et al., 2025b, §4).

Local y global en Python

Si un nombre se vincula dentro de un bloque, es local a ese bloque, salvo que se declare global o nonlocal. Si se usa una variable local antes de que tenga valor, Python lanza UnboundLocalError (Python Software Foundation, s.f.-c, §4.2.1–4.2.2).

Resolución y sobrecarga

En Java, la firma de un método es su nombre más los tipos de sus parámetros. Los métodos sobrecargados se distinguen por la cantidad y el tipo de los argumentos; el tipo de retorno no cuenta (Oracle, s.f.-a).

En Python, def es una sentencia ejecutable que vincula el nombre de la función a un objeto función (Python Software Foundation, s.f.-e). Un segundo def con el mismo nombre vuelve a vincular ese nombre.

Tiempo de vida

Lapso durante el cual un objeto tiene memoria asignada. En C hay duración automática, estática, de hilo y asignada (cppreference.com, s.f.-b). Si una variable de bloque se declara static, tiene duración estática aunque solo sea visible dentro de ese bloque (cppreference.com, s.f.-b): alcance y tiempo de vida no coinciden.

En Java, el entorno elimina los objetos cuando ya no hay referencias a ellos (recolección de basura) (Oracle, s.f.-e). En Python, los objetos nunca se destruyen explícitamente: cuando se vuelven inalcanzables pueden ser recolectados (Python Software Foundation, s.f.-b).

Asignación

Las variables pueden contener valores (tipos valor) o referencias (tipos referencia). En Java, los datos primitivos se copian por valor y los objetos por referencia (Gallardo et al., 2025b, §1.2.2). En Python, varios nombres pueden vincularse al mismo objeto; esto se conoce como aliasing (Python Software Foundation, s.f.-a).

Variables y constantes

En Java, una constante static final no puede reasignarse: hacerlo es un error de compilación. Por convención, su nombre va en mayúsculas (Oracle, s.f.-d). En C, un objeto const no es asignable (cppreference.com, s.f.-a). En Python, escribir las constantes en mayúsculas es una convención de estilo (van Rossum et al., 2001).

En la programación imperativa el estado del programa se modifica (Gallardo et al., 2025b, §1.2); en la funcional los valores son inmutables y no hay estado interno (Gallardo et al., 2025a, §1.1.1).

No confundas

No confundas ligadura con tipado. Ligadura estática o dinámica (U3) responde cuándo se asocia un atributo a una variable. Tipado estático o dinámico (U4) responde cuándo se verifican los tipos: un lenguaje es de tipado estático si comprueba los tipos al compilar, y dinámico si lo hace en ejecución (Oracle, s.f.-b). Usan las mismas palabras, pero son preguntas distintas.

02Código comparado

Una variable global y una local con el mismo nombre

La variable local tapa a la global dentro de la función. Afuera, la global sigue intacta.

x = "global"

def demo():
    x = "local"
    print("dentro:", x)

demo()
print("fuera:", x)

Salida al ejecutarlo: dentro: local / fuera: global

public class Alcance {
    static String x = "global";      // atributo de clase

    static void demo() {
        String x = "local";          // variable local
        System.out.println("dentro: " + x);
    }

    public static void main(String[] args) {
        demo();
        System.out.println("fuera: " + x);
    }
}

Salida al ejecutarlo: dentro: local / fuera: global

#include <stdio.h>

char *x = "global";

void demo(void) {
    char *x = "local";
    printf("dentro: %s\n", x);
}

int main(void) {
    demo();
    printf("fuera: %s\n", x);
    return 0;
}

Salida al ejecutarlo: dentro: local / fuera: global

03Actividades de práctica

Cada actividad indica cuándo terminaste. No pases a la siguiente hasta cumplirlo.

Actividad 1 · Traza en Python Tutor

Individual · 30 min

Python Tutor muestra los marcos de las funciones y los objetos durante la ejecución (Guo, 2013). Usa este código:

asistentes = []

def registrar(nombre, lista):
    mensaje = "Hola " + nombre
    lista.append(nombre)
    return mensaje

saludo = registrar("Ana", asistentes)
print(saludo, asistentes)
  1. Pega el código en pythontutor.com y ejecútalo paso a paso.
  2. En cada paso anota qué marcos existen y qué nombres hay en cada uno.
  3. Señala qué variables son globales y cuáles son locales.
  4. Indica en qué paso desaparece mensaje y por qué.
  5. Explica por qué asistentes cambió aunque la función no lo nombra.

Terminaste cuando tienes una tabla paso a paso con los marcos y respondiste los pasos 4 y 5 con lo que muestra la herramienta.

Actividad 2 · Constantes en tres lenguajes

En equipo de trabajo · 40 min
  1. Escriban en Python, Java y C un programa con una constante (mayúsculas, final y const).
  2. Intenten reasignar la constante en los tres.
  3. Registren qué lenguaje lo impide, en qué momento (al compilar o al ejecutar) y el mensaje exacto.
  4. Comparen lo que vieron con la documentación citada en esta unidad.

Terminaste cuando tienen los 3 programas ejecutados y una tabla de 3 filas con: ¿lo impide?, ¿cuándo?, mensaje de error.

Actividad 3 · Sobrecarga sí o no

Individual · 20 min
  1. En Java escribe dos métodos: area(double lado) y area(double base, double altura).
  2. Llama a los dos y verifica cuál se ejecuta en cada caso.
  3. Intenta lo mismo en Python con dos def y observa qué pasa.
  4. Logra el mismo comportamiento en Python con un parámetro por defecto.

Terminaste cuando los dos lenguajes calculan el área de un cuadrado y de un rectángulo con el mismo nombre de función, y explicas en 2 oraciones por qué Python necesitó otra estrategia.
