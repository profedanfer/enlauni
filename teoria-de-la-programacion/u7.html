01Repaso

Origen

Simula introdujo el concepto de clase a fines de los años sesenta: una abstracción que agrupa estado y funciones. El paradigma se popularizó a principios de los ochenta, en gran parte por Smalltalk (Gallardo et al., 2025b, §1).

Clase y objeto

Una clase es el plano a partir del cual se crean objetos individuales; cada objeto es una instancia de su clase (Oracle, s.f.-f). Los objetos de software tienen estado y comportamiento (Oracle, s.f.-g).

En Python, todo objeto tiene identidad, tipo y valor. La identidad no cambia después de crearlo, y el operador is compara identidades (Python Software Foundation, s.f.-c). En Java, == compara referencias y equals compara valores (Gallardo et al., 2025a, §1.2.3).

Constructor

En Java, una clase tiene constructores que se invocan para crear objetos; se declaran como un método, pero con el nombre de la clase y sin tipo de retorno (Oracle, s.f.-d). En Python, una clase puede definir el método especial __init__ para dar a cada instancia un estado inicial (Python Software Foundation, s.f.-b).

Mensaje

Los objetos interactúan enviándose mensajes, es decir, invocando métodos. Alan Kay, creador del término «orientado a objetos», afirmó que la gran idea de Smalltalk es el envío de mensajes (Gallardo et al., 2025b, §1).

Encapsulamiento

Ocultar el estado interno y exigir que toda interacción se haga mediante los métodos del objeto (Oracle, s.f.-g). En Python no existen variables de instancia privadas; por convención, un nombre que empieza con guion bajo se trata como parte no pública (Python Software Foundation, s.f.-b).

Reutilización e independencia

Con la herencia, una clase nueva reutiliza los campos y métodos de una clase existente sin tener que escribirlos ni depurarlos de nuevo (Oracle, s.f.-a). Organizar el código en objetos aporta modularidad, ocultamiento de información, reutilización y la posibilidad de reemplazar un objeto por otro (Oracle, s.f.-g).

Tipos de herencia

En Java, salvo Object, toda clase tiene exactamente una superclase directa: herencia simple (Oracle, s.f.-e). Java no permite extender más de una clase para evitar los problemas de la herencia múltiple de estado, pero sí admite herencia múltiple de tipo: una clase puede implementar varias interfaces (Oracle, s.f.-b). Python soporta una forma de herencia múltiple (Python Software Foundation, s.f.-b).

Una clase abstracta no se puede instanciar, solo heredar, y puede declarar métodos abstractos que implementan sus subclases (Oracle, s.f.-e). En Python se usa el decorador abstractmethod (Python Software Foundation, s.f.-a).

Polimorfismo

Las subclases pueden definir sus propios comportamientos y compartir parte de la funcionalidad de la clase madre (Oracle, s.f.-c). Un mismo método puede estar definido en varias clases, y el código que se ejecuta depende del tipo de la instancia (Gallardo et al., 2025b, §1).

Ligadura dinámica

La JVM llama al método del objeto al que apunta la variable, no al definido por el tipo de la variable; esto se llama invocación de método virtual (Oracle, s.f.-c). Como el código a ejecutar solo se conoce en tiempo de ejecución, también se habla de enlace dinámico o late binding (Gallardo et al., 2025b, §6.5). Es la ligadura dinámica de la Unidad 3, aplicada a métodos.

No confundas

Java no admite herencia múltiple de clases, pero sí de tipos. Una clase extiende una sola superclase y puede implementar varias interfaces (Oracle, s.f.-b). Python, en cambio, permite heredar de varias clases (Python Software Foundation, s.f.-b).

02Código comparado

Polimorfismo y ligadura dinámica

El recorrido envía el mismo mensaje, area(), a figuras distintas. Ningún if pregunta el tipo: cada objeto responde según su clase. C no tiene clases; la versión en C imita el mecanismo con un struct y un puntero a función.

from abc import ABC, abstractmethod
import math

class Figura(ABC):
    @abstractmethod
    def area(self):
        pass

class Circulo(Figura):
    def __init__(self, r):
        self.r = r
    def area(self):
        return math.pi * self.r ** 2

class Rectangulo(Figura):
    def __init__(self, b, h):
        self.b, self.h = b, h
    def area(self):
        return self.b * self.h

for f in [Circulo(1), Rectangulo(2, 3)]:
    print(type(f).__name__, round(f.area(), 2))

Salida al ejecutarlo: Circulo 3.14 / Rectangulo 6

abstract class Figura {
    abstract double area();
}

class Circulo extends Figura {
    double r;
    Circulo(double r) { this.r = r; }
    double area() { return Math.PI * r * r; }
}

class Rectangulo extends Figura {
    double b, h;
    Rectangulo(double b, double h) { this.b = b; this.h = h; }
    double area() { return b * h; }
}

public class Main {
    public static void main(String[] args) {
        Figura[] figuras = { new Circulo(1), new Rectangulo(2, 3) };
        for (Figura f : figuras) {
            // ligadura dinámica: se ejecuta el area() de la clase real
            System.out.printf("%s %.2f%n", f.getClass().getSimpleName(), f.area());
        }
    }
}

Salida al ejecutarlo: Circulo 3.14 / Rectangulo 6.00

#include <stdio.h>

/* C no tiene clases: se imita con struct + puntero a función */
typedef struct Figura {
    const char *nombre;
    double a, b;
    double (*area)(struct Figura *);
} Figura;

double area_circulo(Figura *f)    { return 3.14159265 * f->a * f->a; }
double area_rectangulo(Figura *f) { return f->a * f->b; }

int main(void) {
    Figura figuras[] = {
        {"Circulo", 1, 0, area_circulo},
        {"Rectangulo", 2, 3, area_rectangulo}
    };
    for (int i = 0; i < 2; i++)
        printf("%s %.2f\n", figuras[i].nombre, figuras[i].area(&figuras[i]));
    return 0;
}

Salida al ejecutarlo: Circulo 3.14 / Rectangulo 6.00

03Actividades de práctica

Cada actividad indica cuándo terminaste. No pases a la siguiente hasta cumplirlo.

Actividad 1 · Del registro a la clase

Individual · 40 min
  1. Parte del registro Estudiante de la Unidad 4.
  2. Conviértelo en una clase con atributos no públicos.
  3. Agrega un método actualizar_promedio(nuevo) que use una guarda para rechazar valores fuera de 1 a 5.
  4. Agrega un método resumen() que devuelva un texto con los datos.
  5. Crea 2 objetos con el mismo estado y compáralos: con == e is en Python, o con == y equals en Java.

Terminaste cuando tu clase rechaza un promedio inválido sin detener el programa y explicas qué te mostró la comparación sobre la identidad de los objetos.

Actividad 2 · Jerarquía con polimorfismo

En equipo de trabajo · 50 min

Dominio: los vehículos de una empresa de logística (moto, furgón y camión).

  1. Definan una superclase Vehiculo con atributos comunes y un método costo_envio(km).
  2. Creen 3 subclases que sobrescriban costo_envio con reglas distintas que ustedes definan.
  3. Guarden un objeto de cada subclase en una misma lista.
  4. Recorran la lista y llamen a costo_envio(100) sin usar ningún if que pregunte el tipo.
  5. Marquen con un comentario la línea donde ocurre la ligadura dinámica.

Terminaste cuando el recorrido imprime tres costos distintos sin ningún if sobre el tipo y la línea de la ligadura dinámica está marcada y explicada.

Actividad 3 · Modularidad y ocultamiento

Individual · 25 min

Una clase Sistema hace todo: guarda clientes, calcula descuentos, imprime facturas y envía correos.

  1. Lista todas las responsabilidades que tiene esa clase.
  2. Propón cómo dividirla en clases con una responsabilidad cada una.
  3. Indica qué estado oculta cada clase y qué métodos ofrece a las demás.
  4. Dibuja qué clase necesita conocer a cuál.

Terminaste cuando tienes al menos 3 clases nuevas, cada una con su responsabilidad, su estado oculto y sus métodos, y un esquema de flechas.
